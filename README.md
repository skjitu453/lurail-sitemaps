# Lurail sitemaps

This repository hosts the multilingual XML sitemaps for `www.lurail.com`.

- Sitemap index: `https://sitemaps.lurail.com/sitemap-index.xml`
- Chinese: `https://sitemaps.lurail.com/sitemap-zh.xml`
- English: `https://sitemaps.lurail.com/sitemap-en.xml`
- Japanese: `https://sitemaps.lurail.com/sitemap-ja.xml`

The `CNAME` file configures the GitHub Pages custom domain as
`sitemaps.lurail.com`. Do not remove it while this site is published.
